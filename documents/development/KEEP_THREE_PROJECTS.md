for all nine retained scenarios remain; registry and directory-scope regression
tests were added. Only obsolete generated bytecode for the deleted entrypoint was

## Run and review

The local validation frontend/simulator are left running on 5173/8765 for review.
Open any of the three URLs at the top of this report, or choose a project through
the settings gear. Use Scenarios to run it. A server serves one project/session at
a time and switches on Start; it does not autoplay merely because a page opens.

If processes have stopped, run these in separate terminals from the repository root:

```bash
.venv/bin/python simulator/server.py --project aquasense
```

```bash
npm --prefix frontend run dev
```

Or use `./quickstart.sh aquasense` when the ports are free. All three project URLs
work with the same frontend/server. For quick scenario review choose 600x for
AquaSense/FactSafe or 10x for FireScout. Data remains explicitly simulated, with
missing/stale states preserved.

