## Source access and responsible collection

- All 21 READABLE record URLs returned relevant titles/content through web open during the pilot. This is a session readability check, not an assertion that every origin returned HTTP 200 or will remain accessible. The validator only checks URL syntax.
- Daviteq `https://www.iot.daviteq.com/measurements/gas` timed out twice through direct open. Search-indexed official text was retained as F06, UNVERIFIED / LOW, and excluded from accessible-company counts and quantitative evidence.
- Legacy `https://www.flir.ca/suas/uas-for-firefighting/` returned 404. Current camera-category page is accessible; its narrower scope is explicit in S07. An initially tried Honeywell industrial-manufacturing path returned 404; discovery located the working gas-detection solution page.
- Playwright navigation and read-only DOM extraction succeeded on Innovasea and AKVA. Third-party console errors/warnings were observed. AKVA exposed duplicate carousel/cookie headings; section summaries exclude them. Flyability's zero animated counters were discarded rather than interpreted as real values.
- Direct shell HTTPS initially failed sandbox DNS; approved escalation retry received HTTP 403 on Innovasea robots.txt. No direct-fetch workaround was attempted. Built-in robots retrieval worked for Dräger (selected public paths not disallowed) and DJI (sitemap, no disallow in retrieved content); Innovasea, AKVA, Blackline and Flyability robots were unavailable through that channel. Other domains' robots/terms were not fully audited. No recursive or scheduled crawl was run. Future automated batches must stop until permissions are established.
- Only bounded public pages and short paraphrases/CTA labels were collected. No competitor media, personal contact datasets, gated documents, logins, paywalls or CAPTCHA were accessed. Videos were identified from page text but not watched/analyzed. No form submission or sales contact was authorized or performed.

## Validation results

`python3 scripts/research_dataset.py --export documents/research/*/2026-10-27_sources.json` passed: 7 AquaSense, 7 FactSafe, 8 FireScout; combined 22 unique records. Generated Markdown registers preserve the complete normalized fields. Seven negative cases passed rejection checks: duplicate record, missing field, invalid date, credential-bearing URL, search-only promotion, missing numerical scope and invalid confidence.

Manual numerical checks retained units, time periods and attribution chains. Examples: RYNAN's linked shrimp statistic is a Rabobank forecast reported by FAO; Blackline prices use the initial USD block; DJI thermal pixels are distinguished from visual-image dimensions; NIFC uses the completed 2025 US row. No arithmetic or currency conversion was needed. Missing baselines and methods are explicit.

Local Markdown targets, export reproducibility, Git whitespace and baseline file hashes are checked before final logging. No frontend build, simulator test suite or Docker run is needed: application code/configuration and dependencies are unchanged. No paid provider or unconfigured server is represented as tested. No confirmed existing implementation bug was found; docs/BUGBOOK.md remains unchanged by this task.
