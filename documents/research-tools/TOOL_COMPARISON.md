# Research tool comparison

Evaluated 2026-10-27. Decisions apply to this public-web pilot, not every future research task. No new third-party package, account, API subscription, skill or MCP server was installed. Existing search and Playwright cover the minimum requirements. Public vendor prices and plan eligibility can change; recheck before procurement.

Maintenance means the official repository/service and its release/documentation surface were reachable, not a security audit or guarantee. No candidate code was executed. No stale version was pinned or automatic updater added. Exact installed MCP package version was not established; successful invocation establishes operational compatibility for this session.

## Primary sources

- [OpenAI skills](https://developers.openai.com/plugins/concepts/skills): skills supply workflows; MCP supplies tools. A Claude command or marketplace badge does not establish Codex compatibility.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp), [releases](https://github.com/microsoft/playwright-mcp/releases).
- [Hyper marketing skills](https://github.com/hyperfx-ai/marketing-skills), [Lusha competitor play](https://www.lusha.com/campus/plays/competitor-intel-skill/).
- [AgentPatch repository](https://github.com/ziboshao/AgentPatch).
- [AgentPatch marketplace consumer docs](https://agentpatch.ai/docs/consumer/), [official CLI announcement](https://agentpatch.ai/blog/agentpatch-python-cli/), [marketplace SDK](https://github.com/fullthom/agentpatch-python). Consumer-doc and blog details were visible in search-indexed first-party text, but live retrieval failed; do not treat advertised free credits or compatibility as verified current service access. The unrelated `ziboshao/AgentPatch` project is Apache-2.0 model-merging research requiring Python/PyTorch and checkpoints, and is also NOT NEEDED. Package-name similarity is insufficient provenance for installation.
- [Firecrawl repository/license](https://github.com/firecrawl/firecrawl), [releases](https://github.com/firecrawl/firecrawl/releases), [pricing](https://www.firecrawl.dev/pricing).
- [Crawl4AI repository/license/setup](https://github.com/unclecode/crawl4ai), [releases](https://github.com/unclecode/crawl4ai/releases).
- [DataForSEO pricing and integration links](https://dataforseo.com/pricing).
- [Ahrefs pricing](https://ahrefs.com/pricing), [developer introduction](https://docs.ahrefs.com/en/api/docs/introduction).
- [Semrush API help](https://www.semrush.com/kb/5-api), [current pricing](https://www.semrush.com/pricing/seo-ai-search/).

Directory discovery also returned G2 MCP, Similarweb and other commercial analytics products. They were not connected or evaluated as required dependencies. Plugin discovery is not proof of account access. No useful missing capability justified a connection suggestion during this pilot.
